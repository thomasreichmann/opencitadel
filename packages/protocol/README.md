# @opencitadel/protocol

Wire types and validators shared by every [OpenCitadel](https://github.com/thomasreichmann/opencitadel)
component:

* server listings and heartbeats;
* the `plugin.json` schema;
* the `.tar.gz` package format;
* SteamID and semver helpers;
* an A2S_INFO client;
* minisign-compatible package signing;
* zstd stored frames;
* registry trust types.

No runtime dependencies. Requires Node.js 22.13 or newer.
