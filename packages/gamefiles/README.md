# @opencitadel/gamefiles

[Deadlock](https://store.steampowered.com/app/1422450/Deadlock/) install discovery (Steam
libraries, WSL paths) and a formatting-preserving `gameinfo.gi` (KeyValues) editor. The editor
tags its own edits so they can be removed exactly. Used by
[OpenCitadel](https://github.com/thomasreichmann/opencitadel)'s host and player tools.

No runtime dependencies. Requires Node.js 22.13 or newer.
